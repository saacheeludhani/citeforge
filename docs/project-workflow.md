# CiteForge — Project Workflow

## Overview

CiteForge follows a feedback-driven workflow to evaluate webpage citation performance, identify content gaps, improve weak passages, and check content consistency.

1. Topic Input

The workflow begins with an assigned topic that defines the subject of the webpage to be evaluated.

2. Query Strategist

Relevant queries are generated to test how effectively AI-powered search systems discover and cite the webpage.

3. Page Builder

A structured webpage is created using HTML and CSS, with JSON-LD used to provide structured metadata.

4. Citation Arena

The webpage is evaluated against AI search systems to observe citation performance across generated queries.

5. Performance Scoring

Results are assessed using measures such as citation rate, coverage, and claim accuracy.

6. Editor Agent

Weak passages and missing information are identified. Suggested improvements can then be evaluated through another testing cycle.

7. Integrity Audit and Publishing

The Integrity Auditor checks webpage responses for consistency across different user-agent identities. The webpage can then proceed towards publishing after the required checks.

## Feedback Loop

Evaluation results help identify weaknesses, guide content improvements, and support repeated testing.

## Expected Outcome

The workflow aims to make GEO evaluation more evidence-based and encourage accurate, consistent, and transparent webpage content.

## Implementation Status

This document describes the proposed workflow. Individual stages and their results must be verified through implementation and testing.
